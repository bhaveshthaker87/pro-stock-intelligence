# V40.92 acceptance strategy and workaround

## Screener 30-stock audit
The app now exposes a device-side batch audit in Data Sources. Sign in through the official Screener page, tap Check access, then Audit 30 stocks. The audit sequentially requests 30 liquid NSE symbols using the same in-app WebView cookie jar, extracts Industry P/E, Piotroski, PEG and pledged percentage, records source URL, fetch timestamp, period/unit/method and missing-field state, and stops immediately on HTTP 403. Passwords/cookies are not uploaded to CI or printed. A 403 yields a partial report, not fabricated coverage. The app cannot bypass Screener's access controls; persistent 403 requires provider-side authorization or documented export/API rights.

## NSE chart calculation audit
`tools/validate_nse_chart_parity.py` independently replays the dashboard formulas over bundled NSE CM-UDiFF daily EOD rows for 30 liquid symbols. It validates OHLCV rows and reports exact coverage/as-of dates. It mirrors SMA 50/200, Wilder RSI-14 and the causal one-sided Gaussian Nadaraya–Watson envelope (lookback 40, bandwidth 12, multiplier 2.5). Less than 200 rows is reported as INSUFFICIENT_OFFICIAL_HISTORY; no synthetic bars are added. The report is an independent formula/data audit, not an exchange-certified chart feed.

## Live gateway fallback
Development builds use the authorized gateway only when configured and payload validation succeeds; otherwise the app uses bundled official NSE EOD closes/history. If neither source is present, the quote/chart remains UNAVAILABLE. A configured but failing gateway does not silently downgrade to stale EOD. EOD labels include source and session date. Live/intraday is unavailable until an authorized vendor contract, endpoint and secrets are configured.

## Android test strategy
CI runs JVM/unit/UI checks and an Android emulator install/launch/screenshot/logcat smoke test. Physical-device testing remains a separate release gate: install the exact candidate APK on the user's Android handset; verify cold launch, app title, Screener login/session persistence, 403 handling, 30-stock audit stop behavior, no-network mode, EOD source label, chart landscape/fullscreen/zoom/crosshair, file picker and rotation. Attach device model, Android version, APK SHA-256, test date and screenshots/logcat. CI cannot truthfully certify a physical handset.

## Release gates
- CI unit/UI + Kotlin compile + Android lint + debug APK + emulator smoke all green.
- 30-stock Screener audit report has 30 attempted rows or a clearly explained 403 stop; each metric has value or unavailable reason.
- NSE parity report shows at least 30 symbols with 200+ daily bars for full chart acceptance.
- Physical device smoke evidence is attached.
- Live mode remains disabled until the authorized gateway health check and quote/history payload validation succeed.
