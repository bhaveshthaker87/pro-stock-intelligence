## Reproducible Screener audit

`tools/validate_screener_reconciliation.py` creates a 360-row template and validates source, period, unit, status, values, differences and evidence references. A new template is explicitly NOT_TESTED; it cannot pass the production gate until all 360 records are reconciled against authorized Screener exports.

Generate:
```bash
python3 tools/validate_screener_reconciliation.py --template-out data/screener/30-stock-reconciliation.csv
```

Validate a populated export:
```bash
python3 tools/validate_screener_reconciliation.py --input data/screener/30-stock-reconciliation.csv
```

Strict release validation:
```bash
python3 tools/validate_screener_reconciliation.py --input data/screener/30-stock-reconciliation.csv --require-complete
```

## Data mode policy

- AUTHORIZED_LIVE: only with a configured authorized provider and validated fresh payload.
- OFFICIAL_EOD: verified NSE EOD history, labelled EOD with source and date.
- IMPORTED_DATA: user-supplied verified source with period/unit/provenance.
- UNAVAILABLE: no trustworthy source; no price or signal should be fabricated.
