# V40.92 Integrated Recovery — implementation and release gates

## Included in this branch
- Reconciles the pending V40.91 Screener session/metric changes into the recovery branch.
- Sets Android versionName to 40.92 and versionCode to 91.
- Keeps the four metric extraction aliases and source-aware derivations: reported Industry P/E with peer-median fallback (minimum three valid peers), reported Piotroski score with complete-input-only calculation fallback, reported PEG with EPS-CAGR-only derivation, and pledged ownership parsing.
- Removes Yahoo Finance from the active quote and history fallback paths. The app now uses an authorized HTTPS provider gateway when configured, otherwise validated bundled official NSE EOD data for daily chart history/reference values. If neither exists, data is unavailable rather than fabricated.
- Keeps Screener fundamentals separate from quote/candle sources.
- Aligns CI artifact names to V40.92.

## Integrated UI additions
- Adds a compact, responsive Complete Stock Metrics Matrix to the Financials page, grouped into Market, Valuation, Quality & Profitability, Growth, Ownership and Technical categories.
- Every matrix cell displays a source and period/as-of label when available; missing values are explicitly marked unavailable and are never inferred.
- Adds a Chartink scanner launch path and a source-labelled import option. This is intentionally user-driven because no documented public Chartink API was verified; the app does not scrape private endpoints or bypass account restrictions.
- Keeps the existing Overview, Chart & Technical, Financials, Ownership, Peers and News navigation and existing analysis sections intact.

## Explicit external dependencies — cannot be solved by code-only changes
1. Screener may deny native HTTP access with HTTP 403 even after WebView sign-in. The app must surface this and cannot bypass provider access controls. Automated retrieval is only verified when an actual authenticated account request succeeds on a device.
2. Intraday/live quotes and candles require an authorized provider gateway and vendor entitlements. NSE EOD history is daily close data, not live/intraday.
3. A 30-stock reconciliation requires real provider responses and a fixed as-of date. Mocked parser fixtures do not establish provider coverage.
4. Signed release APK requires persistent Android signing secrets; live-data release additionally requires a deployed authorized HTTPS gateway and sanitized real fixtures.

## Required acceptance tests before release
- Run unit/UI tests, JS syntax checks, Android lint, debug APK build, emulator install/launch and diagnostics.
- Verify four metrics for 30 stocks against Screener where accessible; record source, period, units, value and unavailable reason.
- Verify chart OHLCV against official NSE EOD reference rows for at least 30 liquid symbols; reject invalid/out-of-order candles.
- Verify SMA 50/200, RSI-14 and closed-bar Nadaraya–Watson output against known deterministic datasets, including no look-ahead/repaint tests.
- Exercise 403, 401, timeout, 429, 5xx, malformed payload, stale/future timestamp, wrong symbol and cache fallback.
- Verify chart fullscreen, landscape, zoom, crosshair and narrow-screen layout on emulator and physical Android device.
- Do not mark a build production-ready unless actual provider access, data timestamps and physical-device behavior are verified.

## Current status
This branch is an integrated code recovery candidate, not a claim that every external data dependency is active. A green CI run validates code/build/smoke tests; it does not prove the user's private Screener session or licensed live market-data access.
