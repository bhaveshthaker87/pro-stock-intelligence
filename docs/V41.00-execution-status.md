## Required external configuration

The workflow now accepts `PROVIDER_GATEWAY_BASE_URL` from either repository Variables (preferred) or a repository Secret (fallback). The exact configured location/value is not exposed by the GitHub connector; only the Actions runtime diagnostic can report presence. No credential-bearing URLs are accepted.



1. Set repository variable `PROVIDER_GATEWAY_BASE_URL` to an authorized HTTPS provider gateway implementing the documented quote, history, events, dividends and indices endpoints.
2. Set `PSI_KEYSTORE_BASE64`, `PSI_KEYSTORE_PASSWORD`, `PSI_KEY_ALIAS`, and `PSI_KEY_PASSWORD` as GitHub Actions secrets for release signing.
3. Complete an official Screener sign-in inside the app and run the access probe. If the provider continues to return HTTP 403, automated access remains blocked; no CAPTCHA or access-control bypass is permitted.
