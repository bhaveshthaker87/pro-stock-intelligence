## Confirmed baseline defects to address

1. Version drift: Gradle and workflow still identify V42.07 / versionCode 99 despite PR #55 being titled V42.10.
2. NSE MCP policy documentation contradicts itself: the Gradle default is false, while the policy document says enabled by default; later release gates say disabled pending written permission.
3. Gateway timeframe map accepts only `1m`, `3m`, `6m`, `1y`, `2y`, `5y`; unknown ranges silently default to 366 days.
4. Gateway `_nse_time` assigns UTC directly to NSE-local timestamps.
5. Corporate-event `announcedAt` falls back to the current time when source publication time is missing.
6. Screener query parser fetches one table only and explicitly returns `pagesFetched=1`, `allResultsLoaded=false`.
7. RSI and crash technical scanner is a placeholder returning zero rows and zero checked symbols.
8. Root `index.html` and Android asset `app/src/main/assets/index.html` are not byte-identical at baseline.
