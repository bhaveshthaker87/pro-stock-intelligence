# V42.07 — Zero-budget market-data policy

## User constraints
- Monthly provider budget: INR 0.
- Intended deployment: personal, non-commercial research only.
- Requested feed: delayed, not tick-by-tick.
- Fundamentals: Screener.in only.
- No Yahoo Finance or Moneycontrol live quote fallback.
- Never fabricate, infer, or relabel missing/stale prices.

## Implemented in this branch
- App version is V42.07 / versionCode 99.
- Official NSE MCP access is guarded by `BuildConfig.ENABLE_NSE_MCP_DATA` and enabled by default for personal, non-commercial informational use.
- The Gradle property `enableNseMcpData` defaults to `true`; set it to `false` to disable the feed.
- The guard is placed in the common NSE MCP tool caller, so quote, history, index, and other MCP calls are all blocked unless explicitly enabled.
- The existing bundled official NSE EOD bhavcopy route remains the no-cost fallback and labels values `EOD`, with the trading date and source.
- Existing Screener-only fundamentals path remains unchanged; no alternate fundamentals source is added.
- CI artifact names are aligned to V42.07 and a regression test checks the default-off permission gate.

## NSE MCP usage boundary
NSE's official MCP page describes CM market data as delayed by approximately 1–3 minutes and says the service is for information and learning, not real-time trading, investment advice, or commercial products. This build enables it for this user's personal, non-commercial informational use only. Do not redistribute the data, offer this app as a commercial product, or use the feed as a real-time trading signal. Set `enableNseMcpData=false` to disable it. See the official notice before changing the deployment scope.

## Current zero-budget runtime expectation
- If the latest bundled official NSE EOD history contains a valid row, show the close as **EOD**, not delayed/live.
- If the bundled history has no valid row for the symbol, show **UNAVAILABLE**.
- Do not use a cached quote as a fresh quote.
- Screener fundamentals remain sourced only from Screener. A 401/403 remains an access error; it is not repaired by copying values from another provider.
- Index data is unavailable unless it comes from a permitted, timestamped source. Do not populate index tiles with hard-coded sample values.

## Not claimed as complete
- Official NSE MCP delayed feed is enabled by default for personal, non-commercial informational use; freshness and per-response errors are still validated.
- No independent 30-stock x 18-metric Screener reconciliation has been completed by this change.
- No live provider gateway, index feed, or event feed has been configured.
- This document and static regression tests do not prove the live data service is available or legally permitted.

## Release gates
1. CI build and regression tests pass.
2. Screener login and company-page access are tested with the user's own authenticated session; no password or cookie is collected by CI.
3. 30-stock x 18-metric audit is populated from an authorized Screener export and independently reconciled against the app's parsed values.
4. Delayed MCP remains disabled unless written permission is obtained for this app's exact use.
5. EOD source timestamps, chart calculations, and missing-data states are checked on emulator and physical device.
6. Signed release is withheld until all required release gates are satisfied.

## Completing the 540-field parser reconciliation
If Screener company-page requests return 403, use the in-app **Official Screener CSV export fallback**:
1. In Screener, run a screen containing the stocks you need. Add the required metric columns and include **NSE Code** (or Symbol).
2. Use Screener's official **Export** function to download CSV.
3. Open the app's Data Sources panel, enter the export date/time, choose the CSV, and tap **Import CSV fallback**.
4. The app can use imported rows for fundamentals when the authenticated page request is blocked. Every value is labelled **Screener.in official CSV export (user imported)** and carries the user-entered export timestamp; it is not live or a verified login.
5. Tap **Audit 30 stocks** and **Download app snapshot**. If the live company-page audit is blocked, the app creates a parser snapshot from the imported CSV and records its SHA-256 fingerprint.
6. Export a second, separate Screener CSV after the first import. The reconciliation builder rejects the same file being used on both sides; do not rename/copy the first file and treat it as independent evidence.
7. Run the reconciliation builder below against the app snapshot and the second CSV. Only matched fields with comparable units and source timestamps count as verified. Missing/non-exportable fields remain unverified; never fill them with estimates.

```bash
python3 tools/build_screener_reconciliation.py \
  --app-snapshot app-parser-snapshot-30.json \
  --screener-csv screener-export.csv \
  --screener-exported-at 2026-11-15T12:00:00+05:30 \
  --output data/screener/30-stock-reconciliation.csv
``

Use `--require-complete` only after the report shows 540/540 verified. The app does not mark CSV import as a live authenticated Screener session.
